河道描繪工作臺 / River Tracing Studio V1.2

慈濟大學 經營管理學系 好玩實驗室 作品 · 教學探索版 / Educational Preview

1. 河川與底圖 / River & map

衛星影像僅作為目視參考。使用者須自行確認描繪成果的公開使用權利；不得將影像截圖或影像瓦片包含於匯出檔。

2. 河系管理 / River system

支流沿上游至下游方向描繪。按「連接至主流」後點選主流線條，系統會建立共同匯流節點並切分主流河段。

3. 描繪工具 / Tools

描繪：點擊地圖依序新增節點。移動：拖曳圓點。插入：點選線條加入節點。刪除：點選節點。河口：點擊地圖設定近似出海口。河道方向不自動判定。

4. 河系檔案 / River system file

不使用 Supabase。草稿存於本機瀏覽器；正式資料以一河系一 GeoJSON 檔案匯出，再經審核提交 GitHub。編號依建立順序核發，地理排序另由目錄管理。
