# P136 V0.004 — 資料品質與科學可重現性
來源：WaterwayMap.org 由 OpenStreetMap 衍生之淡水河資料。
原始 GeoJSON： https://waterwaymap.org/river/%E6%B7%A1%E6%B0%B4%E6%B2%B3%20000132413267/geometry.geojson
參照：水利署「河川河道」https://data.gov.tw/dataset/25781
注意：本版使用的是 OSM 衍生資料，並非水利署官方河道線圖。
GitHub Actions 在推送 pipeline 時自動下載並驗證，只有驗證成功才會提交 data/published。
可重現：下載來源原始檔後執行 python scripts/build_tamsui.py --input <source.geojson>。
比對 manifest.json 的 source_sha256 及 published_sha256。原始來源如持續更新，應固定原始檔及 SHA-256 以重現相同輸出。
檢查項目：GeoJSON 可解析、LineString、經緯度範圍、有效點數、唯一 ID。
尚未驗證：上下游流向、支流匯流關係、完整流域覆蓋率。
網站不允許將此圖資的同名或連通河段誤稱為已驗證上游。
若資料取得失敗或驗證不通過，工作流程失敗，禁止發布假資料。
