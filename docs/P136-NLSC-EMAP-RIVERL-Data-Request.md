# P136 官方河川中線資料申請清單 / NLSC Data Request Package

**研究用途：** P136 山河脈絡（River Networks）— 大甲溪水系地理身分驗證。申請人應為實際獲授權的研究者／機構，不能假定已取得使用權。

## 申請標的（請保留正式代碼）

- 資料主管機關：內政部國土測繪中心（NLSC）
- 資料產品：臺灣通用電子地圖
- **正式圖層：河川中線 `EMAP_RIVERL`**
- 用途：與 HydroRIVERS 候選河網比較線條位置及名稱，核對大甲溪主流與支流
- 範圍：優先大甲溪流域；若裁切會妨礙辨識大安溪／烏溪，請提供足以檢查鄰近河川的緩衝範圍
- 格式：優先 SHP（.shp/.shx/.dbf/.prj/.cpg）或 GML/GeoPackage；保留全部名稱、河川類型、等級、測製年月、來源欄位
- 版本與授權：請提供圖資製作／更新日期、座標系統、使用條件、是否可在學術成果中發表經過轉換或簡化的衍生線條，以及是否允許在公開互動網站展示

## 可直接使用的詢問函

**主旨：** 學術研究用途申請「臺灣通用電子地圖—河川中線 EMAP_RIVERL」向量資料及使用條件詢問

國土測繪中心承辦人您好：

我們正在進行「P136 山河脈絡（River Networks）」學術研究與教學專題，目的在於建立可查證的臺灣河川上下游互動地圖。研究第一階段以大甲溪為對象，擬以貴中心臺灣通用電子地圖之「河川中線（EMAP_RIVERL）」作為獨立地理參考資料，核對候選河段的位置、河川名稱及涵蓋範圍。

想請教：
1. 是否有可供學術研究申請或下載的 EMAP_RIVERL 向量資料（SHP、GML 或其他可保留線段幾何與屬性的格式）？申請程序、費用與使用資格為何？
2. 可否提供大甲溪及鄰近大安溪、烏溪的資料，或提供全臺河川中線圖層？若需指定範圍，應採何種方式？
3. 資料是否包含河川名稱、河川類型、河川等級及測製年月？其座標系統與更新日期為何？
4. 是否允許在學術論文中發表統計比對結果，以及在公開的非營利教育網站展示**經轉換或簡化的衍生河川中線**？若需要另外申請公開展示或再利用授權，程序為何？
5. 若 EMAP_RIVERL 不提供直接下載，是否有可供學術研究使用的正式 WFS 或其他向量資料服務？

我們會保留原始資料來源、版本、檔案雜湊值與驗證紀錄；在取得必要授權前，不會公開散布原始資料或其衍生幾何。敬請協助指引適當的申請管道，謝謝。

申請人：［姓名／單位／聯絡方式，由申請人自行填寫］

## 收到資料後的操作

1. 將官方 ZIP 保存在**非公開**的本機工作目錄；不可提交至公開 GitHub repository。
2. 保留官方交付信件、下載連結、日期、授權條款和原始 ZIP。
3. 使用 `scripts/audit_official_vector_archive.py` 確認檔案組成、欄位、投影和 SHA256。
4. 經人工確認實際 DBF 欄位及 CRS 後，使用 `scripts/run_official_centerline_review.py` 進行大甲溪精確名稱擷取及候選河段距離比對。
5. 只有**可公開的統計摘要**才可考慮提交 GitHub；官方原始幾何、衍生幾何及完整明細是否可公開，須依正式授權判斷。
6. 地理身分、上下游拓樸、資料授權為**三個獨立審查關卡**，不因任一測試通過而自動批准發布。
